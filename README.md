# 語彙コンソール — VOCAB CONSOLE

英単語学習用のパーソナルアプリです。知らない単語を登録すると AI が日本語訳・品詞・例文2つを自動生成し、間隔反復（SRS）で復習して定着させます。MRI 診断コンソール風のダーク UI・スマホ縦画面最適化。

単一の `index.html` で完結しており、外部ライブラリ・CDN・ビルド不要。PWA 対応（オフライン起動可）。

## 使い方（GitHub Pages）

1. リポジトリの **Settings → Pages** で「Deploy from a branch」を選び、対象ブランチと `/ (root)` を指定
2. `https://<ユーザー名>.github.io/goi-console/` をスマホの Chrome で開く
3. メニューから「**アプリをインストール**」（ホーム画面に追加）— 全画面のアプリとして起動します

## 機能

- **追加** — 単語を入力すると AI が意味・品詞・例文2つ・派生語を生成
  - 入力は自然な辞書形に補正して保存（例: `In conjunction` → `in conjunction with`）
  - 派生語（例: `adhere` → `adhesive` / `adhesion`）と熟語・フレーズ（例: `stand` → `can't stand` = 我慢できない）をカードとリストに表示
  - 派生語・熟語として登録済みの語を追加しようとすると確認ダイアログを表示（キャンセルで生成せず取りやめ）
  - 例文1は選択した文法パターン（現在完了・受動態・関係代名詞など10種＋おまかせ）を使用。おまかせは生成ごとにランダムに選択
  - 例文2は選択したシーン（業務 / 日常会話）に沿った文
- **復習** — SRS による出題（もう一度 / 覚えた / 簡単）、英→日 / 日→英切り替え、streak 記録
- **リスト** — 検索、状態表示（NEW / DUE / 次回間隔）、AI 再生成・手動編集・削除
- **設定** — 診断（保存セルフテスト）、JSON バックアップ / 復元（上書き更新モードでは SRS 進捗を維持）

## AI 例文生成について

例文生成は Anthropic Messages API を使用します。GitHub Pages 上で単体動作させる場合は、設定タブで自分の Anthropic API キーを設定してください（キーは端末の localStorage にのみ保存されます）。

キーを設定しない運用も可能です:

1. 日中は単語の登録だけ行う
2. 設定タブからエクスポートした JSON を Claude チャットに貼り、例文入り JSON を受け取る
3. 「上書き更新モード」で復元（復習の進捗はそのまま保持されます）

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（HTML / CSS / JS すべて込み） |
| `manifest.json` | PWA マニフェスト |
| `sw.js` | サービスワーカー（オフラインキャッシュ） |
| `icon-192.png` / `icon-512.png` | アプリアイコン |

アプリを更新したら `sw.js` の `CACHE_VERSION` を上げてください（古いキャッシュが自動削除されます）。

## データ保存

学習データはブラウザの localStorage（キー `vocab:deck`）に保存されます。保存は毎回書き込み後に読み戻して検証し、失敗時は画面上部に警告を表示します。端末の変更やブラウザデータ削除に備えて、定期的に設定タブからバックアップしてください。
